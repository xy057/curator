# Media Keys

The keyboard's media keys, a headset's buttons and the system's Now Playing (the lock screen,
the menu bar) play, pause and move the page. Previous and next go by the page's chapters, or
by the score's rehearsal marks where it has none.

A few lines over the browser's own Media Session: what the page is, what is told as it plays
(`curator.on`), and playback moved (`curator.playback`).
