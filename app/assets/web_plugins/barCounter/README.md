# Bar Counter

The bar that sounds, and with Beats its beat ("12.3"), in a corner of the score. The viewer
turns it off in Options; the browser remembers that.

It shows an element of the plugin's own over the frame (`curator.ui.overlay`), a row in
Options (`curator.ui.option`), what the browser keeps for a viewer (`curator.storage`), the
export's settings (`curator.settings`) and the page's colours (`curator.view.theme`).
