# Appearance Menu

Adds **View ▸ Appearance** with Light, Dark and System: Settings ▸ Appearance's theme, a click
away. The one in use is ticked.

Three commands made in a loop, each in the menu `"View/Appearance"` (a menu inside View, made
as its first command is added). `checked` reads the app's setting (`app.setting("theme")`), and
`run` sets it.
