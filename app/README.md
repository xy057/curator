# curated_score (the app)

The Flutter desktop app: the editor, playback, projects and settings. See the
[repository README](../README.md) to build and use it, and
[docs/architecture.md](../docs/architecture.md) for how it is put together.

```bash
flutter test      # from app/: every app test, on the bundled demo project
```

`SCREENSHOT_DIR=/some/folder flutter test test/app_screenshot_test.dart` also saves offscreen
screenshots of the editor (light and dark) for a visual check.
